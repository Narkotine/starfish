**Décision structurante — une snapshot est une disposition *plus une enveloppe*, et l'enveloppe se détecte en la parsant**

- Un fichier de snapshot est le **document schéma 1** auquel s'ajoute `snapshot: {createdAt, note}`. Conséquence : **restaurer une snapshot, c'est appliquer une disposition** (`FenceContainer::applyLayout`), et il n'y a **aucun second format** à tenir synchronisé. `JsonStore` n'a pas eu à apprendre les snapshots : l'enveloppe est retirée, le reste est parsé avec les validations habituelles.
- **L'id n'est pas un champ, c'est le nom du fichier** → il est validé avant de devenir un chemin (séparateurs, `:`, jokers, `.`/`..`, espace initial, point final refusés).
- **Le dossier `snapshots/` vit à côté du document** : `--layout FILE` déplace zones **et** snapshots ensemble.

**Problèmes rencontrés (et pièges à retenir)**

- **Un préfixe d'octets ne décide pas d'un JSON.** `QJsonObject` trie ses clés ; une fenêtre de lecture fixe manque ce qui est écrit en dernier. Le corollaire vaut au-delà des snapshots : pour distinguer deux documents qui partagent un format, **parser**, ne pas sniffer.
- **Un test peut être vert pour la mauvaise raison.** Le cas « l'export n'écrase pas une snapshot » passait avec du code faux, parce que la fixture était petite. Un test dont l'objet est une **borne de taille** doit vérifier qu'il atteint bien cette borne.
- **Le travail non commité est invisible pour le protocole de reprise.** `AGENTS.md` fait lire `STATE.md` → `TODO.md` → `devlog/` ; un arbre de travail en avance sur le dernier commit n'y figure pas. D'où l'ordre de cette session : documenter, puis finir, puis commiter.
- **`QLatin1String(...).arg(<entier>)` ne compile pas** (ambiguïté `QChar`) → `QString::number(...)`.
- **Sortie des tests** : dans cet environnement, `test_starfish_*.exe` **n'écrit rien sur stdout** (même un test qui passe rend 0 octet) ; le verdict est bien rendu par le code de sortie et par `ctest`, mais le **détail** des échecs s'obtient avec `-o <fichier>,txt`. C'est ce qui a permis de lire l'échec initial.
- **`ctest` depuis le bash de l'agent fonctionne** (9/9 en 2,2 s) — contrairement à la note des sessions 10-12 qui le disait bloquant et passait par PowerShell. À re-mesurer si le symptôme revient, mais la note est à considérer comme périmée.
- **`-o` sans nom de format** n'écrit pas le fichier ; la forme `-o fichier,txt` fonctionne.
