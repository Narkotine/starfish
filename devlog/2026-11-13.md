# 2026-11-13

## Session 118 — bouton bloqué ouvert après redimensionnement

- Cause : quitter le mode « Redimensionner le bouton » par un clic sur le disque (hors poignée) terminait le mode à l'appui, puis le relâchement était lu comme un clic pour déployer. L'état devenait déroulé sans `hoverUnrolled`, donc le survol ne refermait plus. Le menu « Enrouler » rétablissait l'état. Particulièrement visible en Diaphragme / Dévoilement (même diamètre, iris ouvert).
- Correctif : ce relâchement n'ouvre plus le bouton ; à la sortie du mode (Échap, clic, inactivité) le disque est forcé compact, la machine de survol est réinitialisée, sans redéploiement immédiat sous le pointeur.
- Sonde (boutons factices, layout.json intact) : entrée depuis ouvert ou compact, Agrandissement et Dévoilement, Simple et Diaphragme ; sorties clic / Échap / inactivité ; ensuite le survol ouvre et referme. Chemin hébergé (`renderFence` / `openProgress`).

## Session 119 — lancer les raccourcis en un clic

- Réglage global dans Réglages → Zones (« Lancer les raccourcis en un clic », shortcutSingleClick, désactivé par défaut). Surcharge par zone et par bouton dans Apparence : Hériter / Oui / Non (singleClick : " / on / off). Le bureau StarFish suit uniquement le réglage global.
- Résolution : on / off l'emportent ; vide = héritage. Un bouton hérite en « oui » (et createButton écrit on), une zone ou le bureau suit le défaut global. Chargement rétrocompatible.
- Lancement au relâchement du clic gauche si le pointeur n'a pas dépassé le seuil de glisser et qu'aucun glisser n'a commencé. Un glisser-déposer reste possible. Un double clic ne lance pas deux fois. Désactivé : zones et bureau restent en double clic. La sélection (Ctrl, rectangle) est inchangée ; un clic simple peut sélectionner puis lancer. Le pulse d'icône des boutons se joue au relâchement.
- Sonde (données factices, layout.json intact) : relâchement lance, glisser ne lance pas, héritage (test unitaire core_single_click). ctest 25/25 ; --ui-probe 131/131 ; i18n 419/419. Pas poussé.
