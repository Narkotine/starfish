# 2026-11-13

## Session 118 — bouton bloqué ouvert après redimensionnement

- Cause : quitter le mode « Redimensionner le bouton » par un clic sur le disque (hors poignée) terminait le mode à l'appui, puis le relâchement était lu comme un clic pour déployer. L'état devenait déroulé sans `hoverUnrolled`, donc le survol ne refermait plus. Le menu « Enrouler » rétablissait l'état. Particulièrement visible en Diaphragme / Dévoilement (même diamètre, iris ouvert).
- Correctif : ce relâchement n'ouvre plus le bouton ; à la sortie du mode (Échap, clic, inactivité) le disque est forcé compact, la machine de survol est réinitialisée, sans redéploiement immédiat sous le pointeur.
- Sonde (boutons factices, layout.json intact) : entrée depuis ouvert ou compact, Agrandissement et Dévoilement, Simple et Diaphragme ; sorties clic / Échap / inactivité ; ensuite le survol ouvre et referme. Chemin hébergé (`renderFence` / `openProgress`).
